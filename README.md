# 🌐 Nabaraj Acharya - Personal Portfolio Website

This is the official repository of [**Nabaraj Acharya**](https://nabrajacharya.com.np) — a full-stack web developer and designer from Nepal.  
The website is built using **Laravel**, **Filament**, **HTML**, **CSS**, and **JavaScript**.  
It showcases my portfolio, education, services, and projects, with a powerful **admin dashboard** for dynamic content management.

---

## 🚀 Features

- 🎨 **Dynamic Admin Panel** powered by [Filament](https://filamentphp.com/)
- 🧠 **SEO Optimized** (Meta tags, OG tags, Twitter cards)
- 🧾 **Dynamic Data Models** for:
  - Personal Information
  - Education Timeline
  - Services
  - Projects
  - SEO Configuration
  - Popups
  - Contact Messages
- 📬 **Contact Form Integration**
- 📱 **Fully Responsive** layout (mobile-first design)
- ⚡ **Fast and Secure** with Laravel backend

## 🗄️ Database Overview

Database Name: `nabrajacharya.com.np`

### 📚 Major Tables

| Table | Description |
|--------|-------------|
| `personals` | Stores personal and brand information |
| `education` | Academic qualifications and institutions |
| `projects` | Portfolio projects with details and links |
| `services` | Services offered (Web Dev, UI/UX, App Dev, etc.) |
| `contacts` | Stores contact form submissions |
| `seos` | Meta, OG, and Twitter SEO data for each page |
| `popups` | Popup banners for announcements |
| `migrations` | Migration tracking for Laravel |
| `sessions` | User session data |
| `cache`, `cache_locks` | Caching and session optimization |
